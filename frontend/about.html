About English Dictionary

A simple, clean, and fast way to look up English words — built as a learning project to explore how a real dictionary application comes together, piece by piece.

What is this dictionary?

English Dictionary is a web-based reference tool for looking up English words. Search any word to see its pronunciation, part of speech, definitions, example sentences, synonyms, antonyms, and related words — all in one clear, uncluttered view.

Purpose

This project exists to make word lookup fast and distraction-free, while also serving as a hands-on learning exercise in building a complete, production-style frontend from scratch — one module at a time.

Main Features

  • Instant word search with live autocomplete suggestions
  • UK and US pronunciation with audio playback support
  • Multiple parts of speech, each with numbered definitions
  • Example sentences shown alongside each individual definition
  • Clickable synonyms, antonyms, and related words
  • Clear loading, error, and "word not found" states
  • Fully responsive design for mobile, tablet, and desktop

Technology

Built with plain HTML5, CSS3, and vanilla JavaScript — no frameworks or external UI libraries. Every interaction, from the search dropdown to the loading spinner, is handled with native browser features and hand-written code.
